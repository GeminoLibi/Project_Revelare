About Case Synchronization

The case synchronization system:

  • Discovers cases in external directories (supports nested structures)
  • Creates new cases automatically in Project Revelare
  • Detects duplicates using quick hash (size+mtime) and full hash (SHA256)
  • Processes new files incrementally (only new files are processed)
  • Flags duplicate files across different cases for review

Note: For scheduled synchronization, use schedule_case_sync.py with Windows Task Scheduler.
